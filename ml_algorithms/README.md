# ML Algorithms templates and examples

This directory contains quick integration examples for 15 ML algorithms. Each script follows a common interface:
- load_data(): returns X_train, X_test, y_train, y_test
- train_and_eval(X_train, X_test, y_train, y_test): trains and returns a dict of metrics

Use these templates to run experiments, collect metrics, and feed results to the MLOps dashboard.
